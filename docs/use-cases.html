Diagnóstico: el libro es casi plano cuando Kelly pide tamaño proporcional al edge — sub-apuesta las señales fuertes, sobre-apuesta las finas.

Fórmula purarisk/functions/kelly.py: f* = p − (1−p)/b, ¼ fraccional, topado por max_bet y max_kelly.
Refinamientooptimization.size_single — cvxpy opcional (batch), fallback Kelly.
Reglas en STRATEGY.mdkelly_fraction:0.25, max_bet_usdc:50, max_exposure:0.15 — editable sin tocar Python.

3 · Riesgo & veredicto

El guardián: AUTO / REVIEW / DISCARD

risk.evaluate aplica el STRATEGY.md (edge thresholds, exposición, drawdown, Kelly) y emite el veredicto. Los flags cualitativos (lesión, partido meaningless) fuerzan REVIEW.

AUTOreglas cuantitativas OK → ejecuta solo.
REVIEWambiguo / flag cualitativo → reporte y espera al CIO.
DISCARDfuera de umbral / evento vencido → no opera.

6 · Seguridad & operación

Dry-run por defectonada se envía sin opt-in explícito (flag + env + key + confirmación).
Kill-switchPOLYMARKET_KILL_SWITCH=1 bloquea toda ejecución al instante.
Armado in-processel interruptor maestro se arma solo dentro del proceso de ejecución; el .env queda en 0.
Idempotenciahash(condition+outcome+strategy+version+fecha) — nunca doble-apuesta.
Cache de clienteautentica 1×/run (2ª construcción 0 ms) → ~6–12 s más rápido, sin rate-limit.
Reproducibilidadfunciones puras + schemas frozen + 165 tests verdes.
