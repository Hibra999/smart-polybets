Modelos predictivos — FIFA World Cup 2026

Cómo el sistema estima la probabilidad de cada resultado adapters/football/

Hay cuatro modelos, todos funciones puras (sin DB, sin red) sembrados desde el ranking FIFA y evolucionados partido a partido con resultados reales del torneo. Tres predicen el ganador (Elo, Bayes, TrueSkill) y se combinan en un ensemble; uno predice goles (Poisson) para mercados Over/Under y BTTS. La probabilidad resultante se compara con el precio de Polymarket para calcular el edge.

Flujo del modelo

1 · Elo ganador

Rating de fuerza actualizado por resultado, con multiplicador por margen de victoria (estilo FiveThirtyEight). K alto porque el Mundial tiene pocos partidos.

# probabilidad esperada (la E de Elo) E_A = 1 / (1 + 10^((R_B − R_A) / 400)) # actualización tras el partido R_A ← R_A + K·m·(S_A − E_A) K=40 · S∈{1, 0.5, 0} m = log(|Δgoles|+1) · 2.2/((|ΔElo|·0.001)+2.2) # margen; empate → m=1 # semilla desde ranking FIFA R_i = 1500 + (FIFA_i − media_FIFA)·0.9
  • Salida: E_A = P(el equipo A gana) — la probabilidad principal del sistema.
  • K=40 (agresivo), margen amortiguado para no sobre‑reaccionar a goleadas entre equipos dispares.

2 · Bayes — Beta-Bernoulli ganador

Creencia probabilística por equipo con incertidumbre explícita. El prior sale del Elo; cada resultado actualiza la Beta. Da media e intervalo creíble.

# prior desde Elo (strength = pseudo-muestra del prior = 4) p = 1/(1+10^((1500−Elo)/400)), clip[0.05, 0.95] α = p·4, β = (1−p)·4 # update: success s ∈ {1 gana, 0.5 empata, 0 pierde} α ← α + s, β ← β + (1−s) # estimación media = α/(α+β) var = αβ / ((α+β)²(α+β+1))
  • Salida: media = P(gana), + var para el intervalo creíble (mide confianza).
  • Complementa a Elo: pondera cuánta evidencia respalda la estimación (equipos con pocos partidos → más incertidumbre).

3 · TrueSkill ganador

Habilidad como distribución gaussiana (μ media, σ incertidumbre), con empates nativos. Port 1v1 puro validado numéricamente vs la librería original (1e‑5).

# probabilidad de ganar P(A) = Φ( (μ_A − μ_B) / sqrt(2β² + σ_A² + σ_B²) ) # parámetros (idénticos a la lib): μ0=25 · σ0=25/3 · β=σ0/2 · τ=σ0/100 # semilla desde Elo μ_i = 25 + (Elo_i − 1500)/40, σ_i = σ0 # update por factores V/W (truncamiento gaussiano), con p_empate≈0.26
  • Salida: P(A) con manejo nativo de empates; expose = μ − 3σ como rating conservador.
  • En la estrategia, el criterio trueskill usa esta probabilidad directamente (los demás usan Elo).

4 · Poisson — goles Over/Under · BTTS

Modelo SEPARADO que predice goles (no el ganador). Tasas de ataque/defensa por equipo con shrinkage hacia la media (pocos partidos por equipo). Sede neutral (Mundial).

# tasas encogidas (pseudo-conteo k=5 hacia la media base) attack_i = (goles_i + k·base)/(partidos_i + k) / base defense_i = (concedidos_i + k·base)/(partidos_i + k) / base # goles esperados (neutral: sin ventaja local, hf=1) λ_home = base · attack_home · defense_away · hf λ_away = base · attack_away · defense_home / hf goles ~ Poisson(λ) (home y away independientes) # mercados derivados de la grilla de marcadores P(Over 2.5) = Σ P(i,j) para i+j ≥ 3 P(BTTS) = (1−e^−λ_home)(1−e^−λ_away)
  • Salida: P(Over/Under), P(BTTS), 1X2 derivado y marcadores más probables.
  • El shrinkage evita que un único resultado extremo dispare las tasas de un equipo con 2–3 partidos.

El ensemble: cómo se elige el lado

research/functions/wc_strategy.py::pick_side combina los modelos según el side_criterion del STRATEGY.md y elige el lado con mayor score.

# blend (criterio activo del Mundial, w = blend_weight = 0.5) score_home = w·Elo_home + (1−w)·Bayes_home score_away = w·Elo_away + (1−w)·Bayes_away lado = HOME_WIN si score_home ≥ score_away, si no AWAY_WIN # probabilidad para el sizing (p_pick): Elo del lado (o TrueSkill si el criterio es trueskill) # edge = p_pick − precio_mercado(Polymarket)
  • Criterios disponibles: elo · bayes · blend (activo) · trueskill.
  • Confianza (HIGH/MEDIUM/LOW) por tamaño de muestra del lado más flaco → hoy MEDIUM (2–3 partidos), razón para quedarse en ¼ Kelly.
  • Filtros opcionales del STRATEGY.md: warmup (saltar hasta la N‑ésima aparición del lado) y filtro Bayes (descartar si la media < umbral).
