Frescura de datos y SessionStart

core/preconditions.py es la fuente de verdad. Evalúa únicamente liga_mx_2026 y nfl_2026.

Chequeo

.venv/bin/python scripts/check_freshness.py
.venv/bin/python scripts/check_freshness.py --json

READ informa y puede continuar. MONEY bloquea violaciones mandatorias. Si además se solicita live, valida signer, POLYMARKET_LIVE y kill-switch.

Codex

.codex/config.toml define un hook SessionStart para startup, resume, clear y compact. Primero ejecuta el checker y luego scripts/generate_reports.py, que actualiza los HTML locales de próximos partidos y backtest hasta hoy. No actualiza fuentes, publica contenido ni coloca órdenes.

--force --reason no es un atajo normal. Sólo se usa con autorización explícita y deja la razón visible.
